# PRMHSyn 当前参数配置

## 🎯 您当前使用的命令参数

```bash
python Model/PRMHSyn.py \
  --dataset ONEIL \
  --threshold 30 \
  --learning_rate 1e-4 \
  --weight_decay 1e-4 \
  --epochs 2000
```
（重构损失已移除，训练仅使用主任务 BCE 监督损失。）

## 📋 关键参数一览表

### 训练参数（您指定的）
- **学习率**: `1e-4`
- **权重衰减**: `1e-4`
- **最大轮数**: `2000`
### 自动使用的默认值（无需指定）
- **学习率调度器**: `reduce_on_plateau` ✅ 已启用
- **早停耐心值**: `100` epochs
- **早停最小改进**: `0.001`
- **梯度裁剪**: `1.0`
- **Dropout**: `0.1` (RHGNN和Decoder)

### 模型架构（代码中固定）
- **嵌入维度**: `512`
- **隐藏层维度**: `128`
- **输出维度**: `256`

## 🔄 工作流程

1. **训练开始**: 学习率 = 1e-4
2. **30个epoch无改进** → 学习率 × 0.5 = 5e-5
3. **再30个epoch无改进** → 学习率 × 0.5 = 2.5e-5
4. **100个epoch无改进** → 触发早停

## ✅ 总结

**核心训练参数**见上表与 `Config.py`，其余多为默认值；具体以当前 `Config.py` 为准。
